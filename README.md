# ITSS 451 — Interactive Cybersecurity Lab Presentation

This repository contains my interactive final project presentation for ITSS 451: Ethical Hacking and Network Defense.

The project demonstrates both offensive and defensive cybersecurity techniques inside a controlled virtual lab environment using Kali Linux and Metasploitable 2.

## Project Coverage

* Reconnaissance and host discovery
* Nmap service and vulnerability scanning
* Metasploit exploitation
* Samba usermap_script vulnerability exploitation
* MQTT traffic interception and command injection
* Node-RED dashboard exposure
* Suricata IDS deployment
* MQTT authentication hardening
* UFW firewall configuration
* Node-RED authentication security

## Technologies Used

* Kali Linux
* Metasploitable 2
* Nmap
* Metasploit Framework
* Mosquitto MQTT
* Node-RED
* Suricata IDS
* UFW Firewall
* HTML, CSS, JavaScript

## Purpose

The goal of this project is to show how insecure defaults and weak configurations can expose systems to attacks, and how layered security controls can reduce those risks.
